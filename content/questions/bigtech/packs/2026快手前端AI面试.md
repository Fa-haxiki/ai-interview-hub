### 简单介绍一下事件循环机制，特别是微任务和宏任务的执行顺序。

事件循环是 JavaScript 处理异步操作的核心机制，通过任务队列的循环调度确保单线程下的非阻塞执行。

- 执行栈清空后，优先检查并清空微任务队列（Microtask Queue）

- 微任务清空后，取出一个宏任务（Macrotask）执行

- 常见的微任务包括 Promise.then、MutationObserver、process.nextTick

- 常见的宏任务包括 setTimeout、setInterval、I/O、UI 渲染

常见坑：

- 误认为Promise构造函数内部是异步的（其实是同步执行）

- 忽略了 await 后面的代码会被包装成微任务

### 在 AI 应用中经常用到流式输出，请说明 SSE（Server-Sent Events）和 WebSocket 的区别。

SSE 是一种基于 HTTP 的单向推送技术，非常适合 LLM 这种服务端持续输出、客户端只读的场景。

- 通信方向：SSE是单向的（服务端到客户端），WebSocket是全双工双向通信

- 协议基础：SSE基于标准HTTP协议，WebSocket是独立的协议（需握手升级）

- 断线重连：SSE 内置了自动重连机制，WebSocket 需要手动实现

- 数据格式：SSE 默认传输文本流，WebSocket 支持二进制和文本

常见坑：

- HTTP/1.1 下 SSE 有 6 个并发连接限制，需配合 HTTP/2 使用- 忘记在服务端设置 Cache-Control: no-cache 追问：

### 如何实现一个带有并发控制的 Promise 控制器?

并发控制的核心是维护一个执行中的任务池，当任务完成后自动触发下一个待执行任务。

- 维护一个待执行队列和当前正在运行的任务计数器

- 每次调用add时，判断计数器是否达到上限，未达到则直接执行

- 执行逻辑中使用finally确保无论成功失败都能触发下一个任务

- 返回一个 Promise，以便外部感知当前任务的完成状态常见坑：

- 任务执行失败后没有释放计数器导致后续任务永久挂起

- 没有正确处理返回值的传递代码示例：

```javascript
class PromisePool {
    constructor(max) {
    this.max = max;
    this.count = 0;
    this.queue = [];
    }
    add(fn) {
    return new Promise((resolve, reject) => {
    this.queue.push({ fn, resolve, reject });
    this.run();
    });
    }
    run() {
    while (this.count < this.max && this.queue.length) {
    this.count++;
    const { fn, resolve, reject } = this.queue.shift();
    fn().then(resolve).catch(reject).finally(() => {
    this.count--;
    this.run();
    });
    }
}
```

function isValid(s) {
    const stack = [];
    const map = { ')': '(', ' ]': '[', '}': '{' };
    for (let char of s) {

    } else {
    stack.push(char);
    }
    }

### 手写题：实现一个简单的 EventBus（发布订阅模式）。

发布订阅模式是解耦组件间通信的常用手段，需支持监听、触发、只触发一次和取消监听。

- 使用Map存储事件名与回调函数的对应关系

- on 方法添加订阅，emit 方法触发执行

- off 方法移除特定回调，once 方法执行后自动移除

- 注意处理回调函数不存在或重复订阅的情况

代码示例：

```javascript
class EventBus {
    constructor() {
    this.events = {};
    }
    on(name, fn) {
    if (!this.events[name]) this.events[name] = [];
    this.events[name].push(fn);
    }
    emit(name, ...args) {
    if (this.events[name]) {
    this.events[name].forEach(fn => fn(...args));
    }
    }
    off(name, fn) {
    if (this.events[name]) {
    this.events[name] = this.events[name].filter(f => f !== fn);
    }
    }
}
```
