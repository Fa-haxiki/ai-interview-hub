```javascript
▼ 代码块
```

### 解释闭包及其常见应用场景

闭包是指函数和声明该函数的词法环境绑定在一起，形成一个“包裹”函数及其外部变量的作用域链。

应用场景：

i. 私有变量：通过闭包实现数据封装，避免外部直接访问。

```javascript
function createCounter() {
    let count = 0;
    return {
    increment: () => count++;
    decrement: () => count--;
    getCount: () => count
    };
}
const counter = createCounter();
console.log(counter_count()); // 0
counter.increment();
console.log(counter_count()); // 1
```

i. 函数工厂：根据不同需求创建不同的函数。

ii. 回调函数和事件处理：事件处理中常常使用闭包来保持对外部变量的引用。

### CSS选择器优先级计算规则

#### 优先级计算顺序：

i. 内联样式 > ID 选择器 > 类选择器 > 元素选择器

ii. 重要声明（!important）总是优先。

### 解释浏览器事件循环机制## 小红书前端面试二面## 题目

事件循环是浏览器中处理异步操作的机制。浏览器的主线程通过事件循环不断从任务队列中取出任务并执行。

#### 执行顺序：

i. 执行同步代码（主线程）。

ii. 执行微任务（如 Promise 的回调）。

iii. 执行宏任务（如 setTimeout、I/O等）。

- 微任务优先级高于宏任务。

### 实现函数柯里化的两种方式

```javascript

3    if (args.length >= fn.length) {
4    return fn(...args);
5    } else {
```

### 解释HTTP2新特性

- 多路复用：允许多个请求/响应在同一个连接上并行传输。

头部压缩：通过HPACK压缩HTTP头部，减少传输数据量。

- 服务器推送：服务器可以主动推送资源到客户端，而不是等客户端请求。

流优先级和依赖：可以设置流的优先级，优化请求的顺序和资源加载。

### React Fiber架构设计思想

- React Fiber 是 React 的一种新的协调算法，旨在提高大规模应用的渲染性能。

#### 。 核心思想：

i. 增量渲染：将渲染任务分解为多个小任务，允许中断和恢复，避免阻塞。

ii. 优先级调度：根据任务的优先级动态决定何时执行。

iii. Fiber节点：每个渲染更新都是一个Fiber节点，具有执行状态、优先级等信息。

### Webpack热更新原理

热模块替换（HMR）允许在不刷新页面的情况下更新模块。

#### 。原理：

i. Webpack 监控文件的变化。

ii. 当发生变化时，Webpack 会将更新的模块发送到客户端。

iii. 客户端接收更新并通过 HMR API 替换更新的模块。

#### 7. Web Workers通信原理

Web Workers 是浏览器中的线程，用于执行并行任务，避免阻塞主线程。

通信：

i. postMessage：主线程和Worker线程之间通过postMessage方法传递消息。

ii. onmessage: 监听消息，处理数据。

#### 8. Node.js事件循环与浏览器差异

- Node.js事件循环：是基于非阻塞I/O的事件驱动模型，Node.js的事件循环主要处理I/O任务、定时器和回调函数。

浏览器事件循环：浏览器事件循环处理的主要是用户输入、渲染和UI更新。
